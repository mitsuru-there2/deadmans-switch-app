iOS release exportのsource mapを確認し、bracesとnode-forgeは含まれていません。含まれるuuid文字列の3ファイルは `expo-modules-core/src/uuid` の別実装で、監査対象のnpm uuidではありません。デコーダーは `vendor/decode-uri-component/index.js` の修正版がbundleへ解決されています。これは今回の生成物の確認であり、将来の依存変更を保証しません。

vendorコピーは `vendor/decode-uri-component/README.md` に出所と変更を記載。Expo Routerが互換な修正版を取り込んだ後に削除します。依存を更新した場合は、`npm ci`、typecheck、Nodeテスト、Expo prebuild、各OS export、監査を再実行してください。
